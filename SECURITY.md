# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | ✅ |
| 1.0.x   | ❌ |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, email **tushararote123@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Affected version(s)

You should expect an initial response within a few days. Once a fix is available, a new release will be published and the reporter credited (unless anonymity is requested).
